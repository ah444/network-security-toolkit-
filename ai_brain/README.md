# AI brain

What the project is, where it is going, why it is built this way, and the way of working behind it, in one place.

| File | Holds |
|---|---|
| [PROJECT_STATUS.md](PROJECT_STATUS.md) | What exists today, and how each claim is known |
| [ROADMAP.md](ROADMAP.md) | What was done from v4 to now, and what comes next |
| [DECISIONS.md](DECISIONS.md) | The plan's decisions D1–D23, the decisions taken during the releases, the rules of work and the terms |
| [REVIEW_DECISIONS.md](REVIEW_DECISIONS.md) | The review committee's decisions RD1–RD4 (v5.3) |
| [careful-engineering](../.claude/skills/careful-engineering/SKILL.md) | The way of working as a skill for any project, with its [templates](../.claude/skills/careful-engineering/references/templates.md) |

The day-to-day tasks stay in the checklists in [`docs/`](../docs/V5.3_CHECKLIST.md), and the original plan with every option weighed in [`docs/IMPROVEMENT_PLAN.md`](../docs/IMPROVEMENT_PLAN.md).

**Using the skill in another project:** copy the `careful-engineering` folder to `~/.claude/skills/` (every project) or to that project's `.claude/skills/` (that project only). This repository keeps its one copy in [`.claude/skills/careful-engineering/`](../.claude/skills/careful-engineering/SKILL.md), and `~/.claude/skills/` holds the other. The two must stay identical: edit one and copy it to the other.
