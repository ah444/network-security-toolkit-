## 1. CLI and web give the same predictions on real data

Script (kept out of the repo): load each export with the CLI's `load_model`, label every
row of a real file with the CLI's `predict_rows`, upload the same bundle through the web
trainer's **Load Model** route (`/load_model`), then send 1,000 randomly sampled rows
(seed 0) one by one to `/predict_loaded` for every model in the bundle and compare.

| Export (trained in the web trainer) | Data | Models | Result |
|---|---|---|---|
| `20261020T122106Z-ba07d02c` (NSL-KDD, 39 MB) | the official `KDDTest+.txt`, all 22,544 rows | Random Forest, Decision Tree, XGBoost, LightGBM | CLI labelled every row (0.0–0.6 s per model); **0 mismatches** with the web app in 4 × 1,000 rows |
| `20261020T110444Z-7cf3ced5` (CIC-IDS2017, 1.9 MB) | a 5 % random sample of `CIC-2017.csv` (141,764 rows, seed 0) | Random Forest, Logistic Regression, Decision Tree | CLI labelled every row (0.1–3.8 s per model); **0 mismatches** with the web app in 3 × 1,000 rows |

The 1.98 GB Random Forest export (`20261020T125523Z-7baf0b28`) was not used: it needs more
free memory than the machine had (see Known limitations in the README).

These are agreement checks, not scores: no metric from them is reported.
