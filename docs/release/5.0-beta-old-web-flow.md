# Old web flow check (5.0-beta gate)

Recorded 2026-10-20 on Windows 10, Python 3.14.3, scikit-learn 1.8.0, at commit `cd1f0d4`.
The web trainer still runs its v4 training code until step 0.4g; this check shows that
the alpha changes (security fixes, workspaces) and the new `toolkit/ids_core` library
didn't change what it does.

## 1. Replay of the recorded click sequences

The two scripted sequences from the baseline (`scripts/baseline_v4.py`, step 0.1b) were
run once more through Flask's test client on the full files, single core, and every
number was compared with `docs/baseline/*.json` (run 1):

| Dataset | Sequence | Result | Balancing | Features | Training |
|---|---|---|---|---|---|
| `DDOS(CIC-2017)_FILTERED_TEST.csv` | S1 all features + recommended balancing | **identical** | none | 14 | 15.3 s |
| `DDOS(CIC-2017)_FILTERED_TEST.csv` | S2 Apply SMOTE → recommended features | **identical** | none | 10 | 10.8 s |
| `KDDTrain+.txt` | S1 all features + recommended balancing | **identical** | class_weight | 41 | 139.3 s |
| `KDDTrain+.txt` | S2 Apply SMOTE → recommended features | **identical** | none | 10 | 565.3 s |

"Identical" means: same features, same balancing method, and the same accuracy, weighted
F1, macro-F1, balanced accuracy, AUC and confusion matrix for every model on validation
and test.

## 2. In the browser, as a user

The app was started with waitress on `127.0.0.1:5000` and used in the desktop app's
browser pane (phone-width view, 375 px):

1. `/dynamic_ids` loads; the workspace bar and **Clear workspace** button show.
2. **Upload**: an 80-row CSV of real CIC rows (40 BENIGN + 40 DDoS, cut from
   `tests/fixtures/cic_ddos_sample.csv`) → "File(s) uploaded successfully!"; preview
   shows 80 rows, 15 columns (14 numeric, 1 categorical).
3. **Analyze Class Distribution** on `Label` → BENIGN 40 (50 %), DDoS 40 (50 %).
4. Four input features chosen with Ctrl+Click, target `Label`, default models
   (Random Forest, Logistic Regression) → **Train Model** → "Models trained", split
   56 / 12 / 12, validation and test tables, confusion matrix (logistic regression,
   test: 7 / 0 / 2 / 3).
5. **Predict** with Random Forest on a real DDoS row → "Predicted Value: DDoS".
6. Export shows its "Paused until v5.0-rc1" note.

Every request of this session returned 200 (`/upload`, `/preview_data`,
`/get_available_models`, `/analyze_class_distribution`, `/configure`, `/predict`); the
server log shows one clean training run. The only console error from the app was its
own `frame-ancestors 'none'` header refusing to be framed, as intended.

## Seen, not blocking (all planned for rc1, step 0.4g)

- The feature and model lists need Ctrl+Click, which touch screens can't do (U5).
- At phone width the data preview table is wider than the screen (354 px in a 285 px
  view), so the page scrolls sideways.
- Column names keep their leading spaces inside the old flow (e.g. `" Label"`), as in
  v4; the new loader strips them (B17).
- Only a small file was used in the browser; full-size files were covered by the
  replay in section 1.
