# 5.0 final: fresh install and UI check

Recorded 2026-10-20 on Windows 10 Enterprise LTSC 2021, Python 3.14.3.

## 1. Fresh install → every menu path

1. `git clone` of the repository at `dde85b5` (5.0-rc2) into an empty temporary folder:
   no `instance/`, no datasets, no `.venv`.
2. `python -m venv .venv` with the system Python 3.14.3, then
   `pip install -r requirements.lock` (56 packages); `pip check`: no broken requirements.
3. With the CLI's "no exported model yet" state as the starting point, a model was
   trained and exported through the web trainer's own routes (`/upload`, `/configure`,
   `/export_model`, Flask test client) on the committed NSL-KDD train fixture: Decision
   Tree + Random Forest, signed with a signing key created on that first export.
4. `python scripts/menu_walkthrough.py` in the clone drove `main.py` through every menu
   path: recon (with the authorization question) → back to the main menu, recon →
   intrusion menu → CLI IDS on the new export, the web trainer (`GET /` and
   `/dynamic_ids` → 200, server stopped), an invalid choice, back; main menu CLI, main
   menu web, exit code 0. **All paths passed.**

The temporary clone was deleted afterwards.

## 2. Web trainer UI at phone width, light and dark

The app was run from `.claude/launch.json` (waitress on `127.0.0.1:5000`) and opened in the
desktop app's browser pane with a **375 × 812** viewport, emulating
`prefers-color-scheme: light` and then `dark`. On each page the contrast audit of
`scripts/contrast_audit.js` (WCAG AA: 4.5:1, 3:1 for large text) was run after showing
every hidden section of the trainer page, so the result, upload, prediction and model
sections were measured too.

| Page | Scheme | Texts measured | Below AA | Page width / scroll width | Other |
|---|---|---:|---:|---|---|
| `/dynamic_ids` (all 11 hidden sections shown) | light | 53 | **0** | 375 / 375 | 15 inputs, all with a label; `lang="en"` |
| `/dynamic_ids` (all sections shown) | dark | 53 | **0** | 375 / 375 | |
| `/` | light | 11 | **0** | 375 / 375 | `lang="en"` |
| `/` | dark | 11 | **0** | 375 / 375 | |

Texts on gradient backgrounds (header, buttons, about 19 per page) can't be described by
one ratio and are not measured, as in the 0.7 audit. Screenshots showed readable text in
both schemes and no horizontal scrolling. Focus outlines are checked by
`tests/web/test_css.py::test_focus_is_visible`; keyboard-only flow and `aria-live` are
v5.1.
