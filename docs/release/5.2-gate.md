`f0f2c06` (the release commit after it changes only the docs and the version). The gate is the
one in the v5.2 checklist: v5.2 adds no check to the plan's §8, so there

## The keyboard only

- **The trainer**, the whole flow on the full files (above): Tab, Shift+Tab, Enter, Space and
  typing only.
- **The menu and the theme at 375 px**: Tab → the logo → Menu; Enter opens it; Tab → the links
  → the Theme button; Enter moves Auto → Light → Dark → Auto, the focus staying on the button;
  Escape closes the menu with the focus back on Menu; Enter on Port Scanner opens the page. A
  focus ring on each.
- **A scan at 375 px**: Tab to Target and Ports (typed), past the protocol and the engine, the
  three lookups' boxes, the authorisation, Start scan. Enter without the authorisation: nothing
  sent, the browser puts the focus on the box (it is `required`); Space ticks it, Enter starts
  the scan; the focus, checked every 50 ms, went Start → Cancel → the Results heading, never the
  page body; Tab then reaches each port card and the three downloads.
- **Scrolling a box with the arrow keys** (left from step 2.2b): Tab reaches the trainer's
  data preview (`KDDTest+`, 4,814 px wide in an 864 px box; `tabindex="0"`, a region with a
  name, `overflow: auto`), and the focus is on it; the arrow keys did not move it in this
  browser pane, which was hidden and drew no frames (keyboard scrolling is animated). Not
  confirmed: see below.
