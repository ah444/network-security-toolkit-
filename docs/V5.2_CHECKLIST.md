## 2.1 Theme button [D2]
Approved 2026-10-25 with: a button in the navbar of both pages that cycles Auto → Light → Dark (Auto, the default, follows the system as before, also while the page is open); the choice saved in the browser (`localStorage`; where the browser refuses storage, the button still works on that page); `theme.js` loaded in the `<head>` before the stylesheet, so a page is drawn in its theme from the start, with no inline script (the CSP unchanged); without JavaScript the button is hidden and the page follows the system; the dark colours written twice in `app.css` (the system's dark unless Light is chosen, and Dark chosen) with a test that keeps the two copies equal, so it works on any browser (not `light-dark()`); two commits.
- [x] **2.1a** This checklist and the plan's v5.2 table. Done in 1 commit
- [x] **2.1b** The button, `theme.js`, the CSS and the tests. Done in 1 commit: `toolkit/ui/web/static/js/theme.js` (a classic script with everything inside one function: Auto removes `data-theme` from `<html>`, Light and Dark set it; the choice kept in `localStorage` as `toolkit-theme`, any other stored value means Auto, refused storage is not an error; the button's text and its name for screen readers say the state; only the script shows the button); both templates load it in the `<head>` before `app.css` and have the button (`hidden`) as the navbar's last item; `app.css`: the system's dark block is now `:root:not([data-theme="light"])`, the same 17 tokens for `:root[data-theme="dark"]`, `.theme-toggle` looks like the navbar's links with a border, and a white focus ring inside the navbar (the page's focus colour was too close to the navbar's indigo; its links get it too); `docs/user_guide.md`: one paragraph; `tests/web/test_theme.py` (12: the script before the stylesheet and the button on both pages, no inline script, the three choices, Auto by default and for a bad stored value, only Light and Dark set the attribute, storage errors caught, the button's text and name, the cycle, no globals, served as JavaScript; 11 failed before the change), `tests/web/test_css.py` (the two dark copies equal value for value, and a colour changed in one copy was caught; dark tokens only override light ones), `tests/web/test_js_modules.py` (`theme.js` is the one classic script).
