# v5.0 Implementation Checklist — "Correct & safe"

Day-to-day driver for v5.0. The **why** behind each item is in [IMPROVEMENT_PLAN.md](IMPROVEMENT_PLAN.md) (IDs in brackets).
Rules:
- Write the test first (it fails), then make the smallest fix, then commit. One item = one commit.
- No v5.1 restructuring during v5.0. Ugly-but-tested code inside `app.py` is fine.
- `(manual)` = checked by hand, not by the test runner.
- "Green" = `python -m pytest` passes on your **Windows** PC with your current **Python 3.14**. Everything is local: no GitHub, no WSL, no nox.
- Linux/macOS: the code follows the portability rules (plan §7, CI host) so it should run there unchanged; it just isn't tested on real Linux/Mac machines.
- Real-data checks come in three tiers: `pytest` on the small fixtures for every change; a seeded stratified **sample** of the real file (CIC 50,000 rows; NSL-KDD 20,000 train rows + the official KDDTest+) for a step's `(manual)` real-data check; the **full** files only at a tag gate, when the step is about speed or memory, or when the numbers are reported (e.g. 0.4d, the 0.5 CLI model). Sample metrics are never reported as results.

### 0.4b Split
- [x] Dedupe before split; report dedupe stats [L4] — test: `tests/ml/test_split.py::test_no_duplicate_across_train_test`, `::test_dedupe_keeps_first_occurrence_and_reports_conflicts`. `toolkit/ids_core/split.py`, settings in `toolkit/config.py` (`SplitConfig`: test share 0.2, seed 42). Fallback chain: official → stratified; temporal → temporal_per_class → group → stratified; temporal_per_class → group → stratified; group → stratified. Equal timestamps never straddle a cut, so within each class every test time is **later** than every train time. User override recorded (`overridden`, `profile_strategy`). *Decision (2026-10-20, user): an official split keeps both files **exactly as published** by default (`official_mode="as_published"`), so benchmark results stay comparable; copies and test rows that also occur in train are counted (`copies_found`, `test_copies`, `test_overlap`) and reported (`OFFICIAL_TEST_OVERLAP_KEPT`, `OFFICIAL_COPIES_KEPT`). Other strategies always dedupe* — tests: `::test_official_files_kept_as_published_by_default`, `::test_official_strict_mode_removes_copies_and_overlap`, `::test_official_mode_only_for_official_split`
